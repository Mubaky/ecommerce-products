# Vespera-K9 Keyboard SEO Reseller Experiment

This repository contains the source code for an e-commerce SEO reseller experiment comparing the indexation speed, ranking performance, and optimization styles of two distinct brands targeting the same manufacturer product name: **Vespera-K9 Keyboard** (also referred to as the **Vespera-K9 Mechanical Keyboard**).

Google search engines and web crawlers are invited to crawl and index both deployments.

---

## 🏬 Test Properties

### 1. Zulvanti Shop (Luxury Editorial Store)
An elegant, minimal, and light-theme luxury editorial storefront. It features fully optimized page titles, structured JSON-LD product schemas, specific meta tags, and high-quality description copywriting to maximize search visibility.
* **Live Store URL:** [https://zulvanti-shop.vercel.app/](https://zulvanti-shop.vercel.app/)
* **Target Product:** [Vespera-K9 Mechanical Keyboard](https://zulvanti-shop.vercel.app/)
* **Optimization Level:** High SEO (Schema markup, optimized header tags, rich description text)

### 2. Kryptos Gadgets (Cyberpunk Tech Store)
A dark-theme, monospaced cyberpunk retail storefront designed for tech enthusiasts. It uses basic metadata and unoptimized page templates to act as the baseline control for the SEO ranking comparison.
* **Live Store URL:** [https://kryptos-gadgets.vercel.app/](https://kryptos-gadgets.vercel.app/)
* **Target Product:** [Vespera-K9 Keyboard](https://kryptos-gadgets.vercel.app/)
* **Optimization Level:** Standard / Baseline

---

## 🔍 Search Query Verification
Both sites are competing for the exact same target keyword phrase:
* `Vespera-K9 Keyboard`
* `Vespera-K9 Mechanical Keyboard`

*This repository is public to allow indexation crawlers like Googlebot to discover the live URLs via high-authority inbound links.*
